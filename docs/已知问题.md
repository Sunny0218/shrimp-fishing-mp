# 已知问题

## 订阅订单提醒后到点未收到微信通知

- 记录时间：2026-08-28
- 当前现象：顾客在订单已经开始计时后，进入订单详情点击订阅订单提醒，倒计时结束后仍未收到微信订阅消息。
- 已观察到的线索：`scanOrderReminders` 可以扫描到到点订单并触发发送；部分订单存在可用的 `订单状态提醒` 订阅授权，但发送阶段可能出现 `openapi.subscribeMessage.send:fail -501001 resource system error. invalid wx openapi access_token`。
- 已做处理：发送函数已对该类微信 OpenAPI 临时错误做重试，并避免把订阅授权直接消费为 `used: true`；订单详情不再使用本地持久缓存判断订阅状态。
- 后续排查：继续用 `scanOrderReminders` 的 debug 返回和 `notification_logs` 集合核对发送结果，确认是微信平台 access token 问题、模板/环境限制问题，还是订阅授权生命周期问题。
